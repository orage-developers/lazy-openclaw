## How to contribute

1. Fork the repository and create a branch from `master`.
2. Work inside the plugin folder, for example `plugins/lazy-loading/`.
3. Run `npm ci`, `npm run typecheck`, `npm run build`, `npm test` and `npm run validate` in that folder.
4. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat(lazy-loading): ...`, `fix: ...`, `docs: ...`).
5. Open a pull request. CI must pass before merge.
6. Add yourself to the list above in the same pull request.
