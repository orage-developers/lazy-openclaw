# lazy-loading (OpenClaw plugin)

Loads agent tools on demand to reduce the prompt sent before the first token.
Target host: OpenClaw `2026.9.5` (experimental plugin APIs; the version is pinned in
`package.json` `openclaw.compat.pluginApi` and `openclaw.build.openclawVersion`).

Status: phase 1 (functionality) in progress. See `../../PLAN.md` for the roadmap,
`docs/baseline.md` for the measured baseline and the default-mode decision, and
`docs/contract.md` for the shared feature contract used by the CLI and the UI.

## Develop

```sh
npm install
npm run build       # tsc + `openclaw plugins build` (regenerates openclaw.plugin.json)
npm run typecheck
npm test            # compiles to .test-build and runs node:test
npm run validate    # `openclaw plugins validate`
```

Try it without touching your real setup, using an isolated state dir:

```sh
export OPENCLAW_STATE_DIR=$(mktemp -d) OPENCLAW_CONFIG_PATH=$OPENCLAW_STATE_DIR/openclaw.json
openclaw plugins install . --force --accept-capabilities
openclaw plugins inspect lazy-loading
```

Do not run `openclaw plugins install .` against your live profile while developing.

## Host permissions

The plugin observes the tools each agent exposes through the `llm_input` hook, which
OpenClaw gates for non-bundled plugins. Grant it in `openclaw.json`:

```json5
{ plugins: { entries: { "lazy-loading": { hooks: { allowConversationAccess: true } } } } }
```

Without it the plugin still loads (the host logs `typed hook "llm_input" blocked`) and
the `catalog` operation only works with an `inventory` supplied by the caller.

## Layout

- `src/contract.ts`: the feature contract (operations and events). Stable surface.
- `src/entry.ts`: wraps the feature entry so the manifest `configSchema` and
  `contracts.tools` are generated from code.
- `src/config/`: TypeBox config schema, defaults and validation.
- `src/catalog/`: per-agent tool catalog (core / deferred / never, schema sizes).
- `src/tools/`: the model-facing `lazy_load_tools` tool.
- `src/control-ui.ts`: placeholder native page (replaced by the UI work).

`openclaw.plugin.json` is generated by `npm run build`; edit the code, not the file.
